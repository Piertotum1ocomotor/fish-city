Описание

Кормушка для рыб автоматическая ZW-82, 0,3л объем.

Автоматическая кормушка для рыб BOYU ZW-82 Состав кормушки: 1.Автокормушка 2.Устройство для крепления к аквариуму 3.Контейнер для корма 4.Крышка контейнера 5.Задвижка для регулировки выходного отверстия автокормушки 6.Винт для фиксации контейнера 7.Батарейки

Настройка автокормушки

Настойка автокормушки. Для снятия контейнера для корма открутите винт, расположенный по центру контейнера. Это облегчает чистку емкости. Засыпьте корм, красной задвижкой отрегулируйте отверстие для высыпания корма. В зависимости от вида корма может потребоваться настройка, производить ее лучше вне аквариума с обитателями. Дисплей автокормушки: Вставьте батареи, на дисплее отобразится нулевое время. Для установки реального времени нажмите SET, клавишей ADJUST установите часы, нажмите SET, клавишей ADJUST установите минуты. После установки времени нажмите SET, в верхнем левом углу дисплея будет мигать цифра 1. Нажмите один раз ADJUST для одиночного прохода автокормушки, два раза для двойного прохода. На экране рядом с цифрой один будут отображаться стрелочки. Без стрелки – автокормушка не будет давать корм в данное время, одна стрелочка – один проход, две стрелочки – два прохода. Нажмите кнопку MODE, на экране отобразится цифра 2. Это второе кормление. Установите клавишами ADJUST и SET требуемое время кормления. После установки времени нажмите SET и клавишей ADJUST требуемое количество проходов автокормушки. По аналогии запрограммируйте остальные два кормления, если требуется. Режим легкой настройки. Перейдите в меню кнопкой MODE до появления на экране буквы S. Кормление может происходить раз в 24 часа, 12 часов, 8 и 4 часа. Для незапрограммированного кормления нажмите клавишу FEEDER. Батарейки в комплект не входят, преобритаются отдельно.
