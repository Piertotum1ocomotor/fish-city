Описание

Jecod PA-60 – это высококачественный внешний фильтр, специально разработанный для обеспечения чистой и здоровой водной среды в вашем пруду.

Аэратор для пруда PA60, 65 л/м, 0,035 mpa, 38 вт, 220 В, Супертихий, профессиональный, для пруда, септиков, аквадизайна Jecod PA-60 – это высокопроизводительный мембранный компрессор из серии Jecod, предназначенный для обогащения воды кислородом. Эффективное решение для решения проблемы нехватки кислорода в водоемах, предотвращая цветение воды и замор рыбы. Мембранный компрессор Jebao PA-60 нашел применение в различных сферах: Аквариумистика. Поддержание оптимального уровня кислорода для рыб и растений. Септики. Обогащение сточных вод кислородом для биологической обработки. Декоративные пруды и озера. Поддержание баланса кислорода для здоровья водной экосистемы. Рыбные хозяйства и установки водоподготовки. Обеспечение кислородом в водных системах. Торговые павильоны с живой рыбой. Создание комфортных условий для живых организмов при продаже.
