Описание

Для подсветки прудов, фонтанов, водопадов, ручьев. Идеально подходит для использования на суше для подсветки ландшафтных объектов: деревьев, строений.

Светильник для фонтана и пруда LED HQ-SB12 DMX, 12вт, 24В, 0,5 м кабель, разноцветная, светодиодная, управляемая пультом ДУ Профессиональный светильник для фонтанов и прудов. Поставляется без трансформатора. Светильники объединяются друг с другом с помощью удобных влагозащищенных соединений и кабелей из ассортимента, длиной 1м, 2м, 5м, 10м. В каждый светильник входит один кабель и выходит один кабель. Таким образом вы можете объединить любое количество светильников в одну гирлянду с индивидуальным расстоянием между всеми светильниками! Трансформатор, продающийся отдельно, также объединяется с проводом от последнего светильника с помощью влагозащищенного разъема. Таким образом, для профессионального подключения светильников марки HQ вам не надо быть электриком, достаточно лишь закрутить гайки на специализированных разъемах светильников. Пульт ДУ и контроллер в комплект поставки не входит и докупается отдельно!
